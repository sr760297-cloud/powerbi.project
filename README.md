Amazon Sales Analysis – Power BI
This project is an Amazon Sales Analysis Dashboard created using Microsoft Power BI. The dashboard is designed to analyze sales performance and provide useful business insights through interactive charts and visualizations.
Project Features
- Monthly sales analysis
- Sales by product category
- Top 10 products by sales
- Sales by state
- Customer status analysis
- Customer city analysis
- Interactive Power BI dashboard
Tools Used
- Microsoft Power BI
- Microsoft Excel
- Data Visualization
- Data Analysis
Key Analysis
The dashboard helps to understand:
- Overall sales performance
- Sales trends over time
- Which product categories generate more sales
- Top-performing products
- Sales distribution across states
- Customer-related sales information
Project Files
- powerbi pro.pbix — Power BI dashboard file
- Dataset used for the analysis
Outcome
The project demonstrates how Power BI can be used to transform sales data into an interactive dashboard and present business information in an easy-to-understand format.
